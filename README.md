For this assignment, I created a personal portfolio around three sections. Each pairs a written self-description with an AI-generated illustration based on my description.

- **My Skills** explains my backend and database work through examples from my projects.
- **My Future Goal** describes my interest in software engineering and the systems I want to learn to design.

I also included my education at DAV Begusarai and BBAU, selected GitHub projects, and my ongoing work on XEEO and Haze.
